# Brand Traders · Sales Analytics (Streamlit)

## Run
    pip install -r requirements.txt
    streamlit run app.py

The 7 CSVs are read from `./data/`. You can also upload them from the sidebar.

## Tabs
Overview · Products · Customers & Geography · Employees · Shipping · Discounts · Data & Model

All tabs respond to the sidebar filters (date, category, country, employee, shipper, discontinued).
